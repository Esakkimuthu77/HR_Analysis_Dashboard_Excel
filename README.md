# HR Analysis Dashboard Using Microsoft Excel

## Project Overview
This project focuses on cleaning and analyzing Human Resources (HR) data using Microsoft Excel and building an interactive HR Analysis Dashboard.

The dashboard provides insights into employee demographics, salary distribution, performance ratings, departments, and locations to help understand the workforce.

## Project Objectives
- Clean and prepare an uncleaned HR dataset.
- Analyze employee demographics and salary distribution.
- Understand employee performance ratings.
- Compare employee counts across departments and locations.
- Create an interactive dashboard using Excel PivotTables, PivotCharts, and slicers.

## Tools and Technologies
- **Microsoft Excel**
- Excel formulas
- PivotTables and PivotCharts
- Slicers
- Data cleaning and data analysis

## Dataset Overview
The dataset contains **499 employee records**.

The main columns include:

| Column | Description |
|---|---|
| Employee ID | Unique employee identifier |
| First Name | Employee's first name |
| Last Name | Employee's last name |
| Gender | Employee gender |
| Age | Employee age |
| Department | Department where the employee works |
| Job Title | Employee's job title |
| Salary | Employee salary |
| Hire Date | Employee hiring date |
| Company Tenure | Length of service at the company |
| Email | Employee email address |
| City | Employee location |
| Performance Rating | Employee performance rating |
| Age Group | Age category created for analysis |
| Salary Range | Salary category created for analysis |
| Tenure Range | Company-tenure category created for analysis |

## Data Cleaning
The project started with an uncleaned HR dataset and prepared it for analysis.

The workflow included:
- Reviewing employee records and column names.
- Identifying and addressing data quality issues.
- Standardizing inconsistent department and other text values.
- Reviewing missing values and correcting inconsistent data where possible.
- Checking date formats and preparing the hire-date field.
- Creating additional columns for Age Group, Salary Range, and Tenure Range.
- Preparing the cleaned data for PivotTables and dashboard visualizations.

## Excel Dashboard

The dashboard includes the following key performance indicators (KPIs):

- **Total Employees:** 499
- **Average Performance Rating:** 3.40
- **Average Salary:** $81,393

### Dashboard Visualizations

**1. Employees by Salary**
- Displays employee distribution across salary ranges.
- Helps compare the number of employees in different salary bands.

**2. Employees by Age**
- Shows the number of employees across age groups.
- Helps understand the workforce's age distribution.

**3. Employees by Performance Rating**
- Displays employee counts by performance rating.
- Helps examine the distribution of performance scores.

**4. Employees by Department**
- Compares employee counts across departments.
- Helps identify departments with larger or smaller workforces.

**5. Employees by Location**
- Shows employee distribution across cities.
- Helps compare workforce distribution by location.

**6. Job Title Slicer**
- Allows users to filter the dashboard by job title.
- Makes it easier to explore employee metrics for selected roles.
